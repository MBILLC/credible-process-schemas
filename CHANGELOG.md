# Changelog

## 0.2.0 — 2026-09-21 (Modelica extension; credibility-level adequacy; library context of use)

### extensions/modelica (2026-09-06)
- A downstream profile for Modelica component libraries (docs/09 applied): vocabulary
  `org.credible-process.modelica` (`record.role`, `family.id`, `credibility.assumptions-ref`,
  `task.external-evidence`, ...), overlays MODELICA-VOC/OVL/STR/LIB, fixtures, and three documents:
  the level a family record supports and the task-to-family level rule, the generated annotation
  schema, granularity and sign-off. Core profiles, matrices and fixtures unchanged.

### core (2026-09-21) — MINOR: new optional keyword, new vocabulary, new fixtures; no existing obligation changed

- `org.credible-process.core`: new optional keyword `credibility.adequacy-override` (`<task level>><model level>`,
  on the citing step, with a signed Approved/Validated entry) — CP-CORE-006 in `credible-process-core.sch`.
  `credibility.level` on an MTMD documented as the model's *ceiling*; mandatory to self-state on an MTMD
  referenced by more than one task lineage (fan-in rule, checked by `csp adequacy`).
- New vocabulary `org.credible-process.library-cou` / `-index` (`vocabulary/Library_COU_Vocabulary.md`):
  one context-of-use declaration SRMD per exported library model (intended use, validity domain, excluded
  uses, credibility ceiling, evidence, declarer) plus a per-library index; rules in the hand-authored
  `profiles/library-cou.sch` (CP-LCOU). Folder conventions: `<Library>/Resources/credible-process/` (Modelica),
  `extra/org.credible-process.library-cou/<Library>/` (FMU/SSP).
- Fixtures: `fixtures/adequacy/<case>/` (11 package cases with expected verdict counts, generated by
  credible-process-tools/examples/make_adequacy_fixtures.py) and single-document `library-cou-*`,
  `stmd-cl3-adequacy-override-*` VALID/INVALID pairs.
- Docs: `docs/11-library-context-of-use.md`; cross-links in 01, 02, 05, 07, 08, 09, glossary, README.
- Profiles regenerated only for the version stamp; no matrix cell changed.

## 0.1.0 — 2026-09-05 (initial extraction)

Obligation matrices confirmed 2026-09-05: cell values as extracted; justifications rewritten to
rest on the prostep CL definitions only (no NASA-STD-7009B reconciliation in this layer).

Extracted from the LOTAR 2026 work project as an industry-neutral layer. Contents: vendored
SSP-LS-Traceability process schemas (STMD/DTMD/MTMD/STC/SRMD), SIC Core and MIC Core; the
`org.credible-process.core` vocabulary (`credibility.level` CL1–CL4 and companions); obligation
matrices and the generated CL1–CL4 conformance profiles for STMD, DTMD, MTMD and SIC Core;
`stc-integrity.sch`; fixtures; the EV-range worked example; documentation.
